Resumo e prioridades

Clique em “Executar auditoria do site” para começar.

O que esta auditoria verifica

  • Disponibilidade das URLs do sitemap
  • Título e meta description ausentes ou repetidos
  • Canonical e robots meta
  • H1 ausente ou duplicado
  • Links internos com destino inexistente/erro
  • Imagens sem texto alternativo (alt)

Nota: auditoria no navegador. Não substitui dados de Search Console nem testes de Core Web Vitals.
